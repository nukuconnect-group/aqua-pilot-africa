# Ajustements Ventes et abonnements
- [ ] Ouvrir Ventes sur l’unité unique ou déjà sélectionnée, avec possibilité de changer.
- [ ] Placer les trois actions nommées sous les données de caisse et ajouter l’icône stock.
- [ ] Permettre les rattachements multi-unités d’une caisse et le report vers son compte désigné, sans modifier les historiques.
- [ ] Mettre à jour les offres d’abonnement et leurs limites.
- [ ] Vérifier les règles, les écrans accessibles et les écritures serveur sans créer de vente réelle.
